Capture tool — UI mockups

A visual pass over the AGS capture window, the recording indicator, and the surrounding surfaces. Same information architecture as the project plan (Screenshot / Recording → Region / Screen / Window), dressed in the shell's existing "hypr-pano" language. Every color is a --color-* token that maps 1:1 onto the runtime @color_* palette.

One door, two modes

The Screenshot / Recording switch is the header — the first question answered before any setting competes for attention.

Targets are objects

Region / Screen / Window sit as icon tiles. You point the tool at something before tuning it.

Settings recede

Micro-labels left, segmented pills right. One loud primary action, tinted per mode (accent for still, red for record).

GIF is its own mode

Choosing GIF swaps in a short frame-rate band and a Size selector, and removes audio entirely — with a note explaining why.

Idle means invisible

The bar cluster renders nothing when there's no recording. Controls materialise only while recording or paused.

Feedback is concrete

Toasts name the outcome, the path, and the next useful action — never a raw backend error.
