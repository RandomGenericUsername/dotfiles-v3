dotfiles-v3 · design review · REQ-113

A real window role, and a kitty that takes the skin

Two approved decisions meet at one new token. D4-B makes surface.window the outer toplevel role; surface.panel stays the layer-shell/in-app panel. D2-B projects a paint-free appearance/kitty.conf for font, size, padding and opacity. The shared token is surface.window.opacity — explicit, never derived from an alpha().

approved direction breaking v3 migration needs visual sign-off colours stay in colors.*

surface.window

Required role, eight tokens. bg, border, border-width, radius, padding, shadow, blur, opacity. A missing window group fails closed; there is no panel fallback.

host geometry

window.radius and window.border-width join the host allowlist. panel keeps its paths for the AGS bar. Seven paths total; padding and opacity are never delegated.

kitty projection

Palette + typed conf. Font family, body size in pt, window padding in pt, background opacity. No paint, no hex, no px suffix; colors.kitty remains the only colour source.

1 · Two outer roles, not two names for one thing

window ≠ panel

A toplevel the compositor decorates and rounds is different from an app-owned layer-shell panel. Both are outer surfaces; only one is a window. Inner cards, controls, cells and pills keep their existing roles.

surface.window — real outer toplevel

Owns outer paint/frame, corner radius, inner padding, shadow, blur and toplevel opacity. Host may delegate radius and border width.

surface.panel — outer panel/overlay

AGS bar, settings surface and layer-shell overlays. Not a decorated toplevel. Keeps its own host delegation and its own consumers.

surface.card — inner card

Notification cards, dialog cards and wlogout action cards. Never the outer frame, even when it visually fills the window.

control · cell · pill

Compact controls, list rows/tiles and badge/capsule shapes. The pill radius stays explicit and is never host-delegated.

No silent alias. The migration copies panel values into authored window groups once. Runtime never does window ?? panel, and a v2 manifest without a window group is rejected rather than rendered with panel values.

3 · kitty: from palette-only to a typed conf

format: conf · artifact: appearance/kitty.conf

The new artifact is paint-free. It renders four knobs from skin tokens and loads after the palette; local.conf stays last so user overrides win. The static config keeps auto_reload_config -1; the runtime reloader still sends SIGUSR1.

Kitty's own defaults fill font, padding, opacity. Only colours come from the skin plane.

# appearance/kitty.conf — no paint, no px/pt suffix
font_family JetBrainsMono Nerd Font
font_size 9
window_padding_width 8.25
background_opacity 0.94
Why bare numbers? kitty's config parser converts the value to a float. font_size 9.0 and window_padding_width 8.25 parse with zero bad lines; 9px and 12px are BadLine(ValueError). The renderer applies the px→pt rule and strips the unit.
Visual decision: 12px body becomes 9pt, not kitty's 11pt default. The conversion is exact, but the perceived size is a design choice. Glass opacity 0.94 is authored, not parsed from its panel alpha.

Breaking token model. Manifest schemaVersion, token version and appearance.json all move to 3. The generation manifest stays version: 3. Every skin and generation hash changes once; old v2 manifests are rejected with a migration error, not silently patched.

5 · Acceptance and open questions

review this before a tag

Must hold

  • surface.window has all eight tokens and is required.
  • No window ?? panel fallback in runtime or templates.
  • rofi/wlogout/GTK outer slots use window; AGS stays panel.
  • Host adds window radius/border-width; panel paths stay.
  • kitty conf is paint-free and uses bare pt numbers.
  • colors.kitty is unchanged and loaded first.

Needs a decision

  • OQ-1: GTK headerbar on window or keep card?
  • OQ-2: first CSS family can be a UI font (Cantarell) — keep or add a terminal family token?
  • OQ-3: glass window.opacity 0.94 or 1.0?
  • OQ-4: accept 12px → 9pt, or change the skin's body size?
  • OQ-5: keep panel host paths for the AGS bar?
