Host rounding, rectangles, and the pill exception

The same app structure rendered by terminal (explicit, square) and terminal-host (follows Hyprland). Live Hyprland rounding is 9px; the host delegates the rectangle roles panel, card, control and cell. surface.pill.radius stays explicit: a pill is a semantic shape, not a rectangle corner.

palette: terminal / dark host rounding: 9 panel/card/control/cell: 9 pill: 2 explicit border: 1 no external assets

What changes

Hyprland decoration:rounding reaches the rectangle roles only: outer panel, card, control and cell. terminal-host follows it.

What stays

The pill token remains authored by the skin. terminal and terminal-host keep 2px; flat and paper keep their 999px capsule.

Why not pills

999 means “half the shortest side”, not a 999px corner. Replacing it with the host scalar breaks capsule semantics and pill-to-control rhythm.

The pill thing, isolated

A pill radius is a shape declaration. In flat and paper, 999px is the capsule sentinel: the browser clamps it to half the shortest side, whatever the pill’s height is. Hyprland’s 9 is a fixed pixel corner for a rectangle. Substituting one for the other is not a unit conversion; it is a different design decision.

Chosen — explicit pill token

terminal-host keeps 2px; flat/paper keep 999px. The skin owns the shape in every host state.

terminal-host · 2px flat/paper · 999px

Capsule reference

A true capsule stays a capsule regardless of its width. The radius is derived from the rendered height, so the host cannot know it.

online selected 2 unread

Not chosen — pill follows 9px

If surface.pill.radius were host-inheritable, the capsule collapses into a rounded rectangle and the pill/control distinction disappears.

online selected 2 unread
Decision: do not add surface.pill.radius to [host].inherit. Keep the contract allowlist unchanged. A future pill policy, if ever needed, must be a separate contract proposal — not an extra path in the host allowlist.
