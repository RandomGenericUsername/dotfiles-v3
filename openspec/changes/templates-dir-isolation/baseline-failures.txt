   Root cause: tests mock `deps.processor` via `processor=mock_processor` in CliDependencies fixture,

   `create_local_processor()` or `resolve_processor()` instead of using `deps.processor`.

   `cli/_helpers.py` to return the mock processor. Tests can also remove the `processor=` kwarg
   from CliDependencies constructor.

   Root cause: The `ProcessResult` output format changed — the info command now serializes

   Tests assert exact output strings that no longer match.

   `MockOutput` in the test only implements the original subset. The protocol check now
   requires all protocol methods.
