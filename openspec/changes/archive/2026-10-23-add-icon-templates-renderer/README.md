# add-icon-templates-renderer

Rewrite the v2 `icon-renderer` module as a new `icon-templates-renderer` CLI tool inside `src/cli-tools/`, adopting the hexagonal (ports & adapters) architecture established by sibling modules `wallpaper-effects-generator` (WEG) and `color-scheme-generator` (CSG). Every v2 command, flag, YAML key, color-scheme format, path-resolution precedence, placeholder-substitution rule, error, and plain-text output is preserved verbatim; no functionality is lost. The new binary is `itr`; the project/package names are kept as `icon-templates-renderer` / `icon_templates_renderer`. Pure-Python only (no `oci-runtime`, no containers, no subprocess). The ~40 v2 bash-e2e scenarios are ported 1:1 to pytest integration tests; sibling-style unit + port-contract tests are added.
