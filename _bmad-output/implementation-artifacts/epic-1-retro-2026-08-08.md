## Successes

1. **Fail-closed layering guard (Story 1.3).** Adversarial review produced 10 findings; the classifier was rewritten fail-closed. Every later story verified "layering guard green," and forward-compatible skips became live assertions as ports/adapters/application/cli landed.
2. **Seam contracts locked by tests.** `test_extra_vars_carry_exactly_install_dir_and_os_family` pinned the extra-vars seam from Story 1.4 through 1.8 — exactly two keys, nothing else. This is the load-bearing contract for Epic 2.
3. **Review discipline.** Every finding across all 8 stories classified and resolved. Story 1.5's review caught the dropped-stderr / no-timeout subprocess path and it was fixed in-story by widening `ProvisionResult` (returncode/stderr) and adding wrapped errors.
4. **Previous Story Intelligence sections.** Learnings propagated across stories (e.g., `uv.sources` relative-path pitfall from 1.1, "do NOT copy the oci-runtime stdlib allowlist wholesale" in 1.3).
5. **Consistent TDD.** RED-first recorded in every story's Dev Agent Record; suite grew 4 → 156 with zero skips.
6. **Maturing test infrastructure.** Story 1.7 extracted triplicated fakes into `conftest.py`; story 1.8 built a CSG-style `_invoke` helper for mock-deps CLI testing.

## Challenges

1. **Mirror-copy-without-scrutiny.** Two real bugs were copies from sibling packages adapted incorrectly: the `uv.sources` relative path in 1.1 (`../../shared/cli-output` copied from CSG; provisioning needs `../shared/cli-output`) and the oci-runtime stdlib allowlist in 1.3 (provisioning domain is pure zero-I/O). The mirror-and-adapt pattern is efficient but demands an explicit "what differs" check.
2. **mypy strict friction on test code.** Repeated `untyped-def` / `attr-defined` / `no-any-return` friction on test params and abstractness checks (mitigated with annotations and targeted `# type: ignore`).
3. **Heavy review loads.** Stories 1.3 (10 findings) and 1.5 (14 findings) carried significant review weight; fixes were valuable but non-trivial.
4. **Known deferred shape debt.** `ProvisionResult.tasks` (anonymous `tuple[str,str]`), `ProvisionManifest.kind` (free-form `str` overlapping `AssetKind`), and `AssetKind` values vs install-spine path segments were deferred and must be reconciled when Story 2.1 manifests land.

## Key Insights

1. **Mechanical enforcement beats convention.** The layering guard and seam-contract tests made architecture violations structurally impossible, not just reviewed-away.
2. **Parse ≠ works.** A rendered settings file parsing is not proof it resolves; verification must assert against provisioned locations, not the repo checkout (hardening carried into Epic 2/3).
3. **Dry-run must be dry.** `--check` must never mutate (guarded `yay`/`makepkg`) — carried as a load-bearing contract for Epic 2/3 tests.
4. **Scope guard sections work.** "What this story is NOT" sections kept stories independently completable and pushed deferred work to the right future stories explicitly.
