A bar indicator's left-click surface: a follower-anchored 312 px panel whose power-mode selector is two levels — a mode rail (three cells, one glyph each) over a variant control that appears only when the selected mode has more than one variant. The owner's model is three glyphs for five selectable things. Drawn at true 312 px and magnified ×1.7; scroll to the true 312 px row at the bottom for 1:1.

True size — 312 px

The same discharging panel, unzoomed. This is the width every AGS overlay in the house uses (SettingsPanel.PANEL_WIDTH). 312 − 2×11 (surface) − 2×8 (rail pad) = 274 px of usable width; three 72 px mode cells plus two 8 px gaps = 232 px, so the rail is centred with slack to spare and never grows the surface.
